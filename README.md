## About this repository

Source for my portfolio at **[jahidem.github.io](https://jahidem.github.io/)** — a black-and-white, interaction-driven single-page site with scroll-driven 3D animations.

**Stack:** Vite · React · TypeScript · three.js ([react-three-fiber](https://github.com/pmndrs/react-three-fiber) + drei) · GSAP · [Lenis](https://github.com/darkroomengineering/lenis) smooth scroll · Framer Motion.

```bash
npm install     # install dependencies
npm run dev     # local dev server
npm run build   # production build to /dist
```

Deployment is automated: pushing to `master` triggers the GitHub Actions workflow
(`.github/workflows/deploy.yml`), which builds the site and publishes it to GitHub Pages.

> **Note:** In the repo's **Settings → Pages**, set **Source** to **GitHub Actions** (one-time setup) for the workflow to deploy.
